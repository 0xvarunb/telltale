# Telltale test set

This page lists the 33 working questions from Telltale's private test set of 50. Each is a job a ship's officer would ask about before starting it. The other 17 questions are held back for one final run and never published, so the tool can't be tuned to them.

For each question, the reports that should come up were chosen before Telltale was asked: by a plain keyword search of every stored report page, then reading the passages it found. Where the right answer is that the reports don't cover the job, the closest case is listed when there is one.

Each report title links to the publisher's page for the report; a TSIB title links to the report's PDF, as TSIB publishes no page for each report.
